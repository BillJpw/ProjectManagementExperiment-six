# 茶店项目协作 - 奶茶店项目管理小程序

## 项目介绍

这是一个专为奶茶店设计的轻量化项目管理小程序，基于uniapp开发，支持在微信小程序平台运行。

## 功能模块

### 1. 用户管理
- 用户登录/退出
- 角色权限（店长、店员、研发）

### 2. 项目管理
- 项目列表展示（按状态筛选）
- 项目详情查看
- 新建/编辑项目
- 项目类型：新品研发、门店活动、设备维护、培训计划

### 3. 任务看板
- 拖拽式看板（待开始、进行中、待验收、已完成）
- 任务详情查看
- 任务评论交流
- 新建/编辑任务

### 4. 奶茶行业特色功能
- 新品研发：配方管理、测试记录、上线状态
- 活动策划：节日促销、新品上线活动
- 设备维护：设备信息、维护记录、状态跟踪
- 原料库存：库存管理、自动预警

### 5. 统计报表
- 项目/任务完成率
- 延期任务提醒
- 团队工作量统计

### 6. 个人中心
- 个人信息查看
- 我的任务/项目
- 设置与帮助

## 技术栈

- 前端框架：uniapp + Vue 2.x
- 状态管理：Vuex
- 样式：SCSS
- 支持平台：微信小程序

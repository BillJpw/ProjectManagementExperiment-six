# 实验六 代码管理工具的使用

- **实验目的**

掌握仓库创建与配置

掌握分支管理策略

掌握版本回退与冲突解决

- **实验准备**

安装 Git（git --version 验证）

注册 GitHub / Gitee / GitLab 账号

配置 SSH Key 或 HTTPS 认证

- **实验内容与步骤**
- 配置环境，git --version截图，

1.将自己的项目上传到你的代码仓库，公开可见（实验报告里需要附上仓库链接）【git push】，仓库链接和截图

2.创建 .gitignore 文件，至少忽略：编译生成的文件（如 node_modules/、*.exe、*.class）、IDE 配置文件（如 .vscode/、.idea/）、临时文件（如 *.log、*.tmp），gitignore文件截图

3.切换到develop分支【git checkout】查看所有分支命令和结果截图

4.修改部分代码（没代码修改可以修改注释）、合并到主分支【git merge】

5.推送本地分支到远程【git push】

6.回退修改的代码、再重新修改提交 【git reset】 4、5、6所有在仓库页面的截图（包含hash码的那种）

- **思考题**
- 之前是否使用过git操作？本次操作比起之前有哪些没使用过的地方？有哪些遇到的困难？

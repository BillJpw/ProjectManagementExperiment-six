总览

本文档提供必要的信息，说明如何使用 Project OLE DB 提供程序访问 Microsoft Office Project 2003 数据。除说明 Project OLE DB 提供程序表结构外，本文档还详细说明了 Project OLE DB 提供程序的其他信息，并给出了 Microsoft ActiveX 数据对象 (ADO) 代码示例。

页首

Project OLE DB 提供程序的重要功能

Project OLE DB 提供程序包括以下重要功能：

  • 在 Project OLE DB 提供程序中添加友好域名称（例如：TaskConstraintDate）。友好域名称允许对数据库进行本地化，并用英语之外的其他语言创建自定义报表。此外，用户还可以使用其本地化语言查看域标签。

    注释  当 Project 以企业模式运行时，只能以英语显示域标签。

  • 添加 15 个新表以支持时间分段数据，工作分配、资源和任务各 5 个，并按分钟、小时、天、周和月进行划分。

    注释   数据库为所有时间分段表的名称使用统一格式：tableTimephasedBytime（例如：AssignmentTimephasedByMinute）。

  • Project OLE DB 提供程序的企业和非企业模式。在表说明左侧的列中使用“E”标记企业域。企业域只可以用于 Microsoft Office Project Professional   2003。
  • 对 Office Web Components 的附加支持。

特征

以下为 Project OLE DB 提供程序的一些独特特征，应该加以注意以免出现意外结果：

  • 有四种数据类型：文本、数字、布尔值和日期[如界面所示（例如，1999 年 12 月 27 日上午 10:30）]。
  • “工期”域的返回值为分钟 * 10（例如，8 小时为 4800），“工时”域的返回值为分钟 * 1000（例如，8 小时为 480000）。
  • 界面上显示为 NA 的日期返回值为 0。
  • 对于界面上显示为 #ERROR 的自定义域中的公式，其返回值为该域的默认值。
  • 对于尚未设置值的自定义域，将返回其默认值。
  • 对于尚未设置标记的自定义域标记域，将返回“-1”。
  • 材料资源的工时值将按界面中定义的单位返回，而不是分钟 * 1000。
  • 使用不带 WHERE 的 SELECT 语句时，返回空的资源行和任务行。使用带有 WHERE 的 SELECT 语句时，不返回这些空行（即使这些行可能满足条件）。

另外，提供程序支持三个注册表项，这些注册表项确定在特定的超时条件发生前所需的秒数。这些注册表项可以在注册表的 HKEY_LOCAL_MACHINE\Software\Microsoft\Office\11.0\MS Project\OLE DB Provider 子项下找到：

注册表项 默认值 说明
TimeoutOnLoad 0 确定在返回项目不可用的错误消息之前，提供程序试图加载项目的时间。（将注册表项设为 0，可以防止发生超时。）
TimeBeforeUnload 37 确定在加载其他项目之后，原有项目保持打开的时间长度。在加载新项目之前，无论该注册表项的设置如何，当前项目都将保留在内存中。
TimeBeforeRefresh 5 确定检查当前项目是否有更新信息的频率。

注释  在编辑注册表之前，应了解在发生问题时如何恢复注册表。注册表编辑不当可能会导致严重问题，可能需要重新安装操作系统。

限制

当前 Project OLE DB 提供程序的使用有下列限制：

  • 不支持读/写访问。
  • 不支持多表查询；必须对要访问的每个表使用不同的查询。
  • 支持只进指针访问 Project OLE DB 提供程序。只进记录集不支持 MovePrevious、MoveFirst 或 MoveLast 等方法。此外，只进记录集也不支持 RecordCount 属性的使用。
  • 不支持联接。但是，通过在关键字、域或行集合间创建以前不存在的关系，图形结构的记录集可以提供相似的功能。还可以按表格格式创建具有层次结构的记录集。有关详细信息，请参阅“ActiveX Data Objects 帮助”中的“Microsoft Data Shaping Service for OLE DB”。
  • 不支持下列运算符：ANY、LIKE 和 IS NOT。
  • 不支持下列聚合函数：Sum、Avg、Min、Max、Count 和 StDev。
  • Project OLE DB 提供程序有一个计时机制，可以通知您何时上载文件，不过只有在发生加载事件时才进行通知。如果 TimeBeforeUnload 值设置为 1，提供程序将只在试图打开其他文件时才检查是否有旧文件，并将该文件设置为读锁定。若要避免该问题，请在完成当前项目时创建一个虚拟文件，强制提供程序加载不存在的文件。这样就会上载刚刚处理的文件，并将虚拟文件设置为读锁定。

使用 Microsoft ActiveX 数据对象的示例代码

Microsoft ActiveX 数据对象 (ADO) 通过一系列的对象、事件、方法和属性提供对 Project OLE DB 提供程序的简单访问。可能用到 ADO 操作的场合包括：访问自己计算机中的提供程序和访问 Project Server 中的提供程序。

使用 ADO 访问自己计算机中 Project OLE DB 提供程序

本示例将访问本地计算机中的 Project 文件，并显示该项目的某些工作分配信息。

注释  若要编译本示例，必须在项目中添加对 Microsoft ActiveX 数据对象 2.1 库或更高版本的引用。有关详细信息，请参阅“Microsoft Visual Basic 帮助中的“设置对类型库的引用”主题。

Sub Connect()
    Dim conData As New ADODB.Connection
    Dim rstAssigns As New ADODB.Recordset
    Dim intCount As Integer
    Dim strSelect As String
    Dim strResults As String
    
    conData.ConnectionString = "Provider=Microsoft.Project.OLEDB.11.0;PROJECT NAME=" & FILE_NAME
' To connect to a Microsoft SQL Server file, you must also supply User ID and Password arguments
'    conData.ConnectionString = "Provider=Microsoft.Project.OLEDB.11.0;User ID=jsmith;Password=MyPass5;  & _
          PROJECT NAME=" & FILE_NAME
    
    conData.ConnectionTimeout = 30
    conData.Open

    strSelect = "SELECT ResourceUniqueID, AssignmentResourceID, AssignmentResourceName, TaskUniqueID,  & _
          AssignmentTaskID," " AssignmentTaskName FROM Assignments WHERE TaskUniqueID > 0 ORDER BY  & _
          AssignmentTaskID ASC"
    rstAssigns.Open strSelect, conData

    Do While Not rstAssigns.EOF
        For intCount = 0 To rstAssigns.Fields.Count - 1
            If (Not IsNull(rstAssigns.Fields(intCount).Value)) Then
                strResults = strResults & "'" & rstAssigns.Fields(intCount).Name & "'" & Space(40 -  & _
                    Len(rstAssigns.Fields(intCount).Name)) & vbTab & CStr(rstAssigns.Fields(intCount).Value) & vbCrLf
            End If
            
            If (IsNull(rstAssigns.Fields(intCount).Value)) Then
                strResults = strResults & "'" & rstAssigns.Fields(intCount).Name & "'" & Space(40 -  & _
                    Len(rstAssigns.Fields(intCount).Name)) & vbTab & CStr("") & vbCrLf
            End If
                   
        Next
        strResults = strResults & vbCrLf
        rstAssigns.MoveNext
    Loop
    
    conData.Close
    
    Open "C:\My Documents\Results.txt" For Output As #1
    Print #1, strResults
    Close #1
        
    Shell "Notepad C:\My Documents\Results.txt", vbMaximizedFocus

End Sub

TaskTimeBCWS 数字 到状态日期或当前日期为止，按时间分段的比较基准累计成本。
TaskTimeCost 数字 任务的总规划（或计划）成本，等于任务所分配的所有资源已完成工时的成本，加上工作分配剩余工时的计划成本；也称作估计完成成本 (EAC)。
TaskTimeCumulativeCost 数字 任务的总成本。
TaskTimeCumulativeWork 数字 任务的总工时（或人-小时）。
TaskTimeCV 数字 到状态日期或当前日期为止，任务达到当前完成程度应花费的成本与实际花费的成本之间的差异；也称作成本差异。
TaskTimeFixedCost 数字 与资源成本无关的任务费用。
TaskTimeOvertimeWork 数字 计划由任务所分配的所有资源完成的加班工时量，按资源的加班费率支付薪酬。
TaskTimeRegularWork 数字 计划由任务所分配的所有资源完成的非加班工时总量。
TaskTimeSV 数字 到状态日期或当前日期为止，任务的当前进度与比较基准计划之间的成本差异；也称作日程差异 (SV)。
TaskTimeWork 数字 计划由任务所分配的所有资源完成的总工时量。
TaskTimeActualFixedCost 数字 与资源成本无关的按时间分段的任务实际费用，按所选成本累算方式计算加班工时。

WBS（工作分解结构）

该表存储项目的 WBS 代码定义及 WBS 代码设置。这些定义与“WBS 代码定义”对话框（“项目”菜单|“WBS”子菜单|“定义代码”命令）中创建的定义相同。

  列名称 数据类型 说明
Project 文本 项目名称，显示为项目位置的路径，例如：C:\pathname\MyProject.mpp。
ProjectUniqueID 数字 引用 Project 表中的有效标识号。
WBSProjectCodePrefix 文本 WBS 代码的前缀。
WBSLevel 数字 为每个 WBS 级别分配的级别，从 1 开始。
WBSSequence 数字 第一级任务的代码字符串类型：
0 数字（有序）；该级别的数字 WBS 代码（默认值）
1 大写字母（有序）；按字母排序的大写 WBS 代码（例如：项目中前三个摘要任务 A、B 和 C）
2 小写字母（有序）；按字母排序的小写 WBS 代码（例如：项目中前三个摘要任务 a、b 和 c）
3 字符（无序）；数字和大写或小写字母的任意组合（例如：项目中前三个摘要任务 Arch1、Const1 或 Insp1）。在键入或输入该代码的字符串之前，Project 在自定义大纲域中显示星号 (*)
WBSLength 数字 在第一级代码字符串中所允许的最大字符数（请参阅 WBSSequence）：
0 任意（默认值）
1 1 个字符
2 2 个字符
... 255 最多 255 个字符
WBSSeparator 文本 用于分隔 WBS 代码级别的字符。在 Project 的“WBS 代码定义”对话框中显示了以下字符；但是，任何符号均可用作 WBS 代码的分隔符：
. 句点（默认值）
+ 加号
/ 正斜杠
- 减号
WBSGenerateNew 布尔值 指定在创建新任务时，Project 是否自动生成新的 WBS 代码。
WBSVerifyUnique 布尔值 指定在编辑任务的 WBS 代码时，Project 是否实施唯一性。

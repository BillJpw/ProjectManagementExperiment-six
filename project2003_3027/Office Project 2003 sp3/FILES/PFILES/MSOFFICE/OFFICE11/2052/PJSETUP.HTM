总览

本文档提供有关 Microsoft Office Project Standard   2003 和 Microsoft Office Project Professional   2003 的安装信息，包括基本安装步骤。

注释  在使用所有企业全局设置功能之前，必须将 Project Professional 2003 连接到 Microsoft Office Project Server 2003。

页首

系统要求

Project Standard 2003 是一个独立程序，不支持与 Project Server 2003 和 Microsoft Office Project Web Access 2003 的协作。对于企业项目管理和工作组协作方面，需要使用 Project Professional 2003。

Project Standard 2003 的需求

  • Pentium 233 MHz 或更高处理器的计算机，建议使用 Pentium III。
  • Microsoft Windows 2000（带 Service Pack 3 或更高版本），或者 Microsoft Windows XP 或更高版本的操作系统。
  • 建议使用 128 MB 或更大的 RAM。
  • 130 MB 可用硬盘空间（硬盘的使用将根据配置不同而变化，自定义安装的选择可能需要更多或更少的硬盘空间）。
  • Super VGA (800 X 600) 或更高分辨率的监视器。
  • Microsoft Internet Explorer 5.01（带 Service Pack 3 或更高版本）、Internet Explorer 5.5（带 Service Pack 2 或更高版本）或 Internet Explorer 6.0（带 Service Pack 1 或更高版本）。为获得最佳效果，请使用 Internet Explorer 6.0（带 Service Pack 1 或更高版本）。

使用特定功能需要附加的项目或服务：

  • 存储在数据库中的项目所需的 Microsoft SQL Server 2000（带 Service Pack 3 或更高版本）、Oracle 8.0.5、Oracle 8i、Oracle 9.2 或更高版本。
  • Internet 功能需要有单独提供的拨号或宽带 Internet 访问。
  • 电子邮件功能需要 Windows 兼容网络和 MAPI 兼容邮件系统。

Project Professional 2003 的需求

  • Pentium 233 MHz 或更高处理器的计算机，建议使用 Pentium III。
  • Microsoft Windows 2000（带 Service Pack 3 或更高版本），或 Microsoft Windows XP 或更高版本的操作系统。
  • 建议使用 128 MB 或更大的 RAM。
  • 130 MB 可用硬盘空间（硬盘的使用将根据配置不同而变化，自定义安装的选择可能需要更多或更少的硬盘空间）
  • Super VGA (800 X 600) 或更高分辨率的监视器。
  • Microsoft Internet Explorer 5.01（带 Service Pack 3 或更高版本）、Internet Explorer 5.5（带 Service Pack 2 或更高版本）或 Internet Explorer 6.0（带 Service Pack 1 或更高版本）。为获得最佳效果，请使用 Internet Explorer 6.0（带 Service Pack 1 或更高版本）。

使用特定功能需要附加的项目或服务：

  • 存储在数据库中的项目所需的 Microsoft SQL Server 2000（带 Service Pack 3 或更高版本）、Oracle 8.0.5、Oracle 8i、Oracle 9.2 或更高版本。如果使用 Project Server 2003 的企业功能，还需要 Microsoft SQL Server 2000。
  • 企业项目和资源管理功能所需的 Project Server 2003。Project Server 2003 有不同的系统要求设置。
  • Internet 功能需要有单独提供的拨号或宽带 Internet 访问。
  • 电子邮件功能需要 Windows 兼容网络和 MSPI 兼容邮件系统。

若要除 Project Professional 2003 之外还使用 Project Web Access，您需要具有上述相同配置的计算机，但以下要求例外：

  • 5 MB 可用硬盘空间（硬盘的使用将根据配置的不同而变化，自定义安装的选择可能需要更多或更少的硬盘空间）。
  • 将任务导入到 Outlook 日历所需的 Microsoft Outlook 2000、Microsoft Outlook 2002 或 Microsoft Office Outlook 2003。

Microsoft Project 安装

可以使用几种方法来安装或部署 Microsoft Project：

  • 从光盘安装
  • 创建管理安装节点
  • 从管理安装节点安装
  • 从管理安装节点运行

注释  在可以从网络共享目录安装或运行 Microsoft Project 之前，必须创建一个管理安装节点。有关创建管理安装节点的详细信息，请参阅创建管理安装节点。

页首

从光盘安装

若要直接从光盘安装 Project Standard 或 Project Professional，请将光盘放到 CD-ROM 驱动器中，并按照安装进程中指示的步骤进行操作。

在安装进程中，会提示您键入或选择以下信息：

产品密钥    键入 25 个字符的产品密钥。您可以在《真品证书》上或在产品 CD 盒背面的标签上找到这组数字。

用户信息   在所给的框中键入“用户名”、“缩写”和“单位”。

接受最终用户许可协议   为了继续安装 Project，必须接受“最终用户许可协议”中的条款。若要接受该协议，请单击“我接受《许可协议》中的条款”复选框。

安装类型   选择所需的安装类型。可选择以下安装类型：

  • “典型安装” 选中此选项将安装运行 Microsoft Project 最常用的所有文件。

    如果正在安装“Microsoft Office 2003 多语言用户界面包”，选择“典型安装”将安装“Office 2003 多语言用户界面包”，其中包含 Office 安装的相同组件。如果正在安装“Office 2003 校对”工具，选择“开始安装”将安装具有默认设置的“Microsoft Office 校对工具”，其中包含最常用的组件。

    若要查看或安装未自动安装的项目，请单击“自定义安装”。屏幕上将显示功能列表。可以从列表中查看已选中的项目，这些项目是在您选择“典型安装”选项时将自动安装的项目。

  • “升级” 如果已安装 Microsoft Project 的早期版本，选择此选项将根据您当前的配置安装新版本的产品。安装程序将删除早期版本。如果您希望保留早期版本不删除，请选择“自定义安装”，这样您就可以指定要保留的应用程序。如果计算机上没有安装早期版本的 Microsoft Project，“升级”选项将不可用。
  • “完全安装” 完全安装将安装 Project 所有组件。
  • “最小安装” 最小安装只安装所需的最少组件。大部分功能将在第一次使用到时安装。如果正在安装的是“Office 2003 多语言用户界面包”或“Office 2003 校对工具”，此选项将不可用。
  • “自定义” 自定义安装使您可以从列表中 Project 所有可用的功能和组件中进行选择。选择您希望如何安装这些功能和组件，决定是否保留当前版本的 Project。
  • “只安装校对工具” 只有在安装“Office 2003 多语言用户界面包”时，此选项才可用。此选项只安装“Office 2003 多语言用户界面包”中的校对工具和其他编辑工具。

注释

  • 如果安装程序不自动开始运行，请选择“开始”菜单，单击“运行”，再单击“浏览”。在 CD-ROM 驱动器中的 Microsoft Project 2003 光盘上，选择 Setup.exe、单击“打开”，再单击“确定”。
  • 如果正在转换 Project 试用版，必须使用 Project 完整版中的产品密钥。可以在您从分销商处购买的软件包中，或从通过网上购买 Project 后收到的确认电子邮件中找到完整版的产品密钥。

创建管理安装节点

将 Microsoft Project 的自定义版本部署给大量用户的最常用方法是在网络服务器上创建管理安装节点，然后让用户从该位置运行安装程序。只有当 Microsoft Project 副本包括 Microsoft Project CD 根目录下的 prjstde 或 prjproe MSI 文件时，才可以创建管理安装节点。

创建管理安装节点相对于从 CD 安装 Microsoft Project 具有一些优点，允许您进行下列操作：

  • 从中心位置管理一组 Microsoft Project 文件。
  • 为所有用户创建标准 Microsoft Project 配置。
  • 管理将来 Microsoft Project 的可控升级。
  • 根据需要安装。

若要创建管理安装节点，请进行下列操作：

  1. 在管理安装节点的网络服务器上创建共享目录。

    网络共享目录必须至少具有 550 兆字节 (MB) 的可用磁盘空间。

  2. 在具有写入权限的计算机上，连接到服务器共享目录。

    该计算机必须运行所支持的操作系统：Microsoft Windows 2000（带 Service Pack 3 或更高版本）或 Windows XP 或更高版本。

  3. 在“开始”菜单上，单击“运行”，再单击“浏览”。
  4. 在 CD-ROM 驱动器中的 Microsoft Project 光盘上，选择 Setup.exe，再单击“打开”。
  5. 在“打开”框中，Setup.exe 之后，键入 /a，再单击“确定”。

    例如：d:\setup.exe /a

  6. 键入您希望为从该位置安装 Microsoft Project 的所有用户定义的单位名称。
  7. 键入您创建的作为管理安装位置的服务器和共享目录。
  8. 键入 25 个字符的产品密钥，再单击“下一步”。

    从这个管理安装节点安装 Project 的用户在安装 Project 或第一次启动 Project 时，不会得到提示要求输入产品密钥，也不需要用户激活产品。

  9. 接受“最终用户许可协议”，再单击“安装”。

    通过在此处接受许可协议，将代表从此管理安装节点安装 Project 的所有用户接受许可协议。

安装程序将文件从 Project 光盘中复制到管理安装节点，解压缩压缩的 CAB 文件，在共享目录的根文件夹中创建文件夹层次结构。在管理安装过程中将自动包括“系统文件更新”。

创建管理安装节点后，请通过向用户提供读取权限来确保他们能够访问该安装节点。

提示    从用户可以安装 Microsoft Project 的管理安装节点创建多个管理安装节点将很有意义。只要为包括路径的任何自定义内容使用相对路径，就可以将完整的文件夹层次结构和文件从一个管理安装节点复制到多台服务器。如果复制文件夹，创建的每个新管理镜像都具有在安装程序中指定的相同默认单位名称。

创建了管理安装节点后，用户可以从此位置安装或运行 Microsoft Project。

  • 若要从管理安装节点安装 Microsoft Project，请在该管理安装节点中找到 Setup.exe。双击 Setup.exe，选择“开始安装”、“完全”或“自定义”，然后按照安装进程中指示的步骤进行操作。
  • 若要直接从管理安装节点运行 Microsoft Project，请在该管理安装节点中找到 Setup.exe。双击 Setup.exe，选择“从网络运行”，然后按照安装进程中指示的步骤进行操作。

    注释  完成安装后，仍要求访问管理安装节点，以便从网络运行 Microsoft Project Standard 或 Microsoft Project Professional。

产品激活

产品激活技术内置于 Microsoft Project 中。产品激活不是注册，而是以减少软件盗版以确保收到的产品达到预期质量为目标的技术。完成安装后，可能会提示您以下列方法之一激活 Microsoft Project：

  • Internet Microsoft 服务器处理激活并自动激活产品。
  • 电话 客户服务代表处理激活和意外情况。

关于产品激活的一些简要说明：

  • 激活是完全匿名的，并且不要求个人识别信息。
  • 每个安装都要求一个唯一的“产品密钥”。可以在装有 Microsoft Project 的光盘盒上找到。
  • 产品激活非常容易。除非将应用程序从一台 PC 移动到另一台 PC 或升级 PC 内的大量组件，否则将只要求您激活 Microsoft Project 一次。
  • 如果 Microsoft Project 是通过 Microsoft 批量授权程序获得的，将不会要求您进行激活。
  • 客户服务代表可提供本地语言支持。

有关 Microsoft 产品激活的详细信息，包括常见问题，请访问 Microsoft Software Piracy 网站。

使用 Microsoft Project Server

如果已经安装 Project Professional 2003，并计划将其用于企业项目管理和工作组协作，必须首先连接到 Project Server 2003，然后指定服务器和帐户设置信息。

连接到 Microsoft Project Server

必须具有 Microsoft Project Server 帐户才可以登录到您单位的项目服务器。若要添加帐户：

  1. 请在“工具”菜单上，指向“企业选项”，再单击“Microsoft Project Server 帐户”。
  2. 单击“添加”。
  3. 在“帐户属性”对话框的“帐户名”框中，键入帐户名称，然后在“Project Server URL”框中键入服务器名称。

    单击“测试连接”，以测试该连接。

  4. 在“连接时”下，选择要使用的帐户，并执行下列操作之一：
    • 若要选择 Windows 身份验证（域/密码），请单击“使用 Windows 用户帐户”。
    • 若要选择 Project Server 身份验证（用户名/密码），请单击“使用 Microsoft Project Server 帐户”，然后在“用户名”框中键入登录到 Microsoft Project Server 时使用的名称。
  5. 如果希望将其设置为连接到 Project Server 时所使用的默认帐户，请单击“设为默认帐户”。
  6. 单击“确定”。
